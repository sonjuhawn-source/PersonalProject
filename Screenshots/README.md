# 스크린샷

1회전 수행 중에 찍었다. 파일명은 [수행용 체크리스트](../docs/qa/test-run-checklist.md) 의 표를 따른다.

루트 [README](../README.md) 의 스크린샷 세 장(`swap` · `boss` · `reward`)과
[UI 설명서](../docs/qa/ui-guide.md) 가 이 폴더를 함께 쓴다. **번호를 매긴 것은 `numbered/`**
에 같은 이름으로 둔다 — 설명서는 번호본을, README 는 원본을 쓴다.

`boss_closeup` · `boss_only` · `excel_tc` · `tint_sim` 은 발표 덱과 이슈용으로 잘라낸 것이라
설명서에는 안 쓴다.
