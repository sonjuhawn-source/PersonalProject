## 문서를 쓰는 규칙

이 저장소가 지켜온 것 셋이다.

**결론이 아니라 근거를 남긴다.** "bounds 를 쓴다"가 아니라 "왜 `transform.position` 이
안 되는가"까지 적는다.

**같은 내용을 두 곳에 두지 않는다.** 하나만 고쳐서 어긋나기 때문이다. 링크는 어긋나지
않으므로 중복 대신 링크를 쓴다.

**확인 못 한 것을 통과로 적지 않는다.** 빌드 결과의 *"확인 못 했다와 안 된다를 섞지
않는다"* 가 TC 결과 열의 규칙이 됐다.
