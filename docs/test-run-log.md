### 발견 1 — 조작 안내에 보상 선택 키가 없다

도움말 화면의 조작표는 다섯 줄이다.

```
← →        이동
Space      점프
F          무기 사용
A          무기 교체 · 대시
ESC        설정
```

오른쪽 설명에 *"보상방에서 셋 중 하나를 고른다"* 가 있지만 **어떤 키인지가 없다.** 실제로는
클릭과 숫자키 `1` · `2` · `3` 이 둘 다 동작한다 (`StageRunner.Update`). 영어 도움말도 같다.

**재시작 `R` 도 조작표에 없다.** 다만 결과 화면에 재시작 버튼이 있어 진행이 막히지는 않는다.

이슈로 등록했다 — 아래 결함 리포트.

### 발견 2 — 효과음 볼륨이 0 으로 시작했다 (결함 아님)

켰더니 효과음이 0 이었다. 레지스트리의 저장값을 확인했다.

```
master   1.0      코드 기본값 1.0
bgm      1.0      코드 기본값 0.8    ← 저장된 값이 기본값과 다르다
sfx      0.0      코드 기본값 1.0    ← 저장된 값
```

**빌드 결함이 아니라 이전 실행에서 저장된 값이다.** 다만 이것이 드러낸 문제가 따로 있다 —
**이 환경은 "처음 설치한 사람"의 상태가 아니다.** `TC-UI-04` · `TC-UI-05` 는 기존 설정이
남은 상태에서만 확인된 것이고, 첫 실행 경로는 한 번도 안 봤다.

`TC-UI-10`(첫 실행 기본값)을 새로 세웠다. 수행하려면 `HKCU\Software\WeaponHero\WeaponHero`
를 내보내 백업한 뒤 지우고 실행한다.

**확인했다 — 통과.** 레지스트리를 비우고 실행하니 효과음 1 · 배경음 0.8 로 떴다. 코드의
기본값(`GameSettings.Load` 의 `GetFloat` 두 번째 인자)과 일치한다. 즉 처음 켜는 사람은
정상적인 소리로 시작하고, **세션 1 에서 본 효과음 0 은 이 환경만의 상태였다.**

같은 형태의 함정이 남아 있는지 생각해 둘 것 — 해상도 · 화면 모드 · 언어도 저장되는
값이라, 기존 설정이 있는 환경과 없는 환경에서 결과가 다를 수 있다.

### TC-SWAP-06 — 미확인이던 주장이 검증됐다

대시 중 이동 · 점프 · 공격 · 재스왑이 **전부 막히는 것**을 확인했다. 포트폴리오 8장의
권한표가 *"스왑은 다섯을 전부 끈다"* 를 주장하는데, 지금까지 **코드 선언만 확인했고
눌러본 기록이 없었다.** 이제 근거가 둘이 됐다.

### TC-CMB-08 — 알려진 미해결이 그대로 재현

공중 공격 → 착지 → **이동하며 공격이 이어진다.** 최종 빌드 노트에 적힌 그대로다
(`AttackState.startedGrounded` 가 진입 시점의 값을 계속 들고 있다).

**새 결함으로 올리지 않는다.** 이미 기록돼 있고 고치지 않은 근거도 남아 있다 —
`!IsGrounded` 로 바꾸면 지상 공격 중 몸이 뜨는 경우의 동작까지 같이 정하게 되는데
그 재료가 1차에 없다. 이번 수행은 **그 판단이 여전히 유효한지 확인한 것**이다.

### 피격 항목이 처음으로 제대로 확인됐다

`TC-CMB-07`(적 공격이 체력을 깎는다)은 W3 에서 `HurtBox.health` 미배선으로 △ 였다.
W4 에서 배선됐지만 그 뒤로 이 항목만 따로 확인한 기록이 없었다. 이번에 확인했다.
