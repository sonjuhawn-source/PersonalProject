## 1회전과 무엇이 다른가

**산출물이 둘이다.** 1회전은 "무엇이 깨졌나"를 찾는 회차였고, 2회전은 **고쳐진 것을
확인하면서 절차를 확정하는** 회차다.

| | 1회전 | 2회전 |
|---|---|---|
| 목적 | 결함 발견 | **회귀 확인 + 스텝 확정** |
| 결과 열 | 비어 있던 것을 채움 | 수정분이 뒤집히는지 본다 |
| 스텝 열 | 비어 있었다 | **초안 108개를 밟아 확정한다** |
| 빌드 | v1.0 (제출본) | v1.1 (수정 반영) |

끝나면 엑셀 요약 시트의 *"테스트 스텝과 사전 조건은 초안이다"* 를 **뗀다.** 제출물에 남은
유일한 미확정 표시다.

### 안 고친 것 둘 — 결과가 그대로여야 한다

```
#151   보상 카드 2택일 때 오른쪽이 빈다      Trivial · Low — 판단해서 안 고쳤다
#143   거절된 패턴이 쿨다운을 소모한다        2회전 뒤로 미뤘다
```

`TC-UI-12` 와 `#143` 용 새 TC 는 **실패로 나오는 것이 정상이다.** 통과로 바뀌면 그게 이상한
것이므로 원인을 찾는다.

## 이번 회전에 새로 들어가는 절차 셋

### 1. 스텝을 밟으며 확정한다

[스텝](test-steps.md)을 띄워 놓고 **그대로 따라간다.** 틀린 줄만 고친다.

**`[확인]` 이 남은 네 곳**이 특히 그렇다. 나머지는 파일에서 확정했다.

| TC | 무엇을 정해야 하나 |
|---|---|
| `TC-SWAP-04` | 스왑 첫 프레임 — 눈으로 판정이 안 된다. 1회전에서 어떻게 봤는지 |
| `TC-ENM-04` | 시체 공격 판정 — 정조준이 안 돼 "플레이하다 지나갔다"였다 |
| `TC-ROOM-06` | 타일 PPU — 캡처로 재나, 임포트 설정을 읽나 |
| `TC-BLD-07` | UI 배선 — 인스펙터를 훑나, 플레이 한 번 돌려 로그를 보나 |

### 2. 문자열을 고쳤으면 글리프를 대조한다

폰트가 정적 아틀라스라 **구운 글자만 있다.** [#159](../../../issues/159) 가 그렇게 났고
**네 번째**였다. 이번 회전에서 문구를 손대면 반드시 본다.

```
charset.txt 와 로컬라이즈 테이블 대조 → 없는 글자가 있으면 charset 에 넣고 다시 굽는다
```

### 3. 첫 실행 경로를 비우고 시작한다

1회전 세션 1 에서 *"효과음이 0으로 시작한다"* 를 보고 기본값을 의심했는데, 실은 **그 환경이
첫 실행 상태가 아니었다.** `TC-UI-10` 이 거기서 생겼다.

```
레지스트리 HKCU\Software\WeaponHero\WeaponHero 를 지우고 시작
```

## 동선

[1회전 체크리스트](test-run-checklist.md)의 세션 0~8 을 그대로 쓴다. **순서를 바꾸지 않는
것이 회귀 확인의 조건이다** — 같은 절차로 다시 봐야 "고쳐졌다"가 성립한다.

세션마다 **스텝 확정이 얹히므로 1회전보다 느리다.** 3시간이 아니라 4~5시간으로 본다.

| 세션 | 1회전 | 2회전에 더해지는 것 |
|---|---|---|
| 0 빌드 전 정적 | 10분 | `TC-BLD-10` 오탐 경고 · `TC-BLD-02` 세 파일 가드 |
| 1 시작 화면 · 설정 | 20분 | **레지스트리 비우고 시작** · `#148` 안내 · `#159` 글자 |
| 2 전투 기본 | 30분 | 스텝 확정이 가장 많은 구간 |
| 3 적과 방 | 30분 | **`#150` 보스 예고** — 잡몹과 나란히 캡처 |
| 4 보상 경계 | 25분 | **`#149` 숫자키·클릭 양쪽** · `#151` 은 그대로 실패 |
| 5 보스와 종료 | 25분 | **`#152` 해상도 변경** — 시작 화면도 같이 |
| 6 사망과 재시작 | 20분 | **`#153` 네 경우** — 언어 2 × 결과 2 |
| 7 시드 | 15분 | 자동 테스트 21개 · 에디터 |
| 8 장시간 | 30분 방치 | `Player.log` 를 **예외와 경고 둘 다** 읽는다 |

5. 덱 8쪽 대표 결함을 **고치기 전/후**로 교체 (`Screenshots/telegraph_compare.png`)

## 판정 규칙은 1회전과 같다

```
✔ 통과   ✘ 실패-수정함   ⏸ 실패-이연   △ 확인 못 함   N/A 해당 없음   ⚙ 자동
```

**확인 못 한 것을 통과로 적지 않는다.** 1회전이 미확인 0 으로 끝난 것이 이 표의 값어치다.
