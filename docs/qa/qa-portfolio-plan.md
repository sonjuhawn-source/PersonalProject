## 지켜야 할 것

**원본은 md 이고 엑셀은 파생물이다.** 내용을 고칠 일이 생기면 `test-cases.md` 를 고치고
엑셀을 다시 뽑는다. 엑셀을 직접 고치기 시작하면 둘이 갈라진다.

스텝을 md 에서 엑셀로 옮기는 쪽은 [`tools/qa/apply_test_steps.py`](../../tools/qa/apply_test_steps.py)
로 저장소에 있다 — `test-steps.md` 를 고치고 다시 돌리면 엑셀이 따라온다. 시트 구조 자체는
`WeaponHero_TC.xlsx` 에 남아 있다.

**테스트 스텝 열을 채우고 확정했다** (107/109 · N/A 두 칸은 비워 둔다).

2026-09-28 에 **[스텝](test-steps.md) 109개를 먼저 뽑아 두고**, 2회전 세션 0~8 을 그대로
밟으면서 틀린 줄을 고쳤다. 초안은 조작법 · TC 의 선행조건과 기대결과 · UI 설명서 · 테스트
메서드 이름에서 나온 것이라 기억이 아니다.

문서가 답하지 못해 `[확인]` 으로 표시해 둔 11곳은 **2026-10-04 에 0 이 됐다.** 파일 이름에서
`draft` 를 뗐고, 엑셀 요약의 *"스텝과 사전 조건은 초안이다"* 도 뗐다 — **제출물에 남아
있던 유일한 미확정 표시**였다.

참고한 TC 서식은 열이 6개뿐인데 **그중 하나가 테스트 스텝**이고 242항목이 전부 채워져
있었다. 재현 절차를 쓸 수 있는지가 QA 의 핵심 역량이라, 이 칸이 비면 산출물이 절반만
있는 셈이다.
