# W4 빌드 노트 — v0.4

> 작성 2026-08-27 (빌드 직전) · 관련: [W4 계획](3주차%20다음%20빌드%20계획.md) · [로드맵](../roadmap.md)

**런 한 판이 처음부터 끝까지 돌아간다.** 시작 → 전투 → 보상 → 보스 → 결과 → 재시작.

W3 빌드 이후 **이슈 12개**가 들어갔고, 그중 넷(`#88`·`#90`·`#93`·`#121`)과 콜라이더 변경이
**모든 방에 영향**을 준다.

---

## 조작

**시작 화면이 없다.** 실행하면 바로 1층이므로 이 표가 유일한 안내다 ([#120](../../issues/120)).

| 동작 | 키보드 | 게임패드 |
|---|---|---|
| 이동 | **← →** (화살표) | 좌스틱 · D패드 |
| 점프 | **Space** | A (남쪽 버튼) |
| 공격 | **F** | X (서쪽 버튼) |
| 무기 스왑 | **A** | RB |
| 재시작 | **R** | — (없음) |

**재시작은 런이 끝난 뒤에만 먹는다.** 전투 중에 눌러도 아무 일이 없다.

### 눌러도 아무 일이 없는 키

바인딩만 있고 구현이 없다. 눌러보고 "고장났나" 하지 않도록 적어둔다.

```
D · S     Skill1 · Skill2    #51 · #52 가 1차 범위 밖으로 확정되면서 소멸
E         Interact           쓰는 곳이 없다
Esc       Pause              일시정지 화면이 절단됐다 — 종료는 Alt+F4
```

## 이 빌드의 수치

### 무기 3종

콤보 한 사이클 전체 기준이다.

| | 사이클 | 총 데미지 | DPS | 리치 |
|---|---|---|---|---|
| 창 | 1.64s (3타) | 48 | **29.3** | 1.25 |
| 검 | 1.31s (3타) | 35 | **26.7** | 1.10 |
| 활 | 0.49s (1타) | 8 | **16.3** | **6** (투사체) |

**활은 [#122](../../issues/122) 에서 잡았다.** 사거리 24 → 6, 관통 3 → 2,
`recovery` 0.2 → 0.35. 데미지는 안 건드렸다 — 이미 최저값이었다.

```
활     딜 낮음 · 압박 없음 · 안전         →  견제
근접   딜 높음 · 경직 + 넉백으로 묶음      →  압박
```

스왑 쿨다운은 셋 다 3.3초. 스왑 중에는 대시 + 무적이 붙는다.

### 적 2종

`Enemy.prefab` 공통 — `maxHealth 30` · `moveSpeed 2` · `detectRange 4.5` ·
`staggerTime 0.15` · `deathDelay 0.35`.

| | 패턴 | 사거리 | 성격 |
|---|---|---|---|
| 돌진형 | `Bite` · `Lunge` | 0~0.95 · 0.8~1.6 | `maxHeightDiff 0.5` — 같은 층에서만 |
| 원거리형 | `Shoot` | 0~4 | `maxHeightDiff 100` — 층을 안 가린다 |

**역할을 가르는 것은 사거리가 아니라 `maxHeightDiff` 다.** `.cs` 를 하나도 안 만들고
`AttackPattern` SO 와 프리팹 변종만으로 갈렸다 ([#74](../../issues/74)).

### 보스 — 오우거

```
maxHealth 250      detectRange 10      패턴 3개 · 페이즈 1
```

| 패턴 | 예고 | 사거리 | 데미지 | 무게 | 쿨다운 |
|---|---|---|---|---|---|
| `OgreSmash` | 0.4 | 0~1.8 | 8 | 3 | 1.2 |
| `OgreCharge` | 0.8 | 1.6~3.5 | 10 | 2 | 4 |
| `OgreThrow` | 0.6 | 3~10 | 6 | 2 | 2.5 |

**셋 다 `interruptible: 0` 이다.** 예고 중에 맞아도 안 끊긴다 — 이게 없으면 붙어서 연타하는
것만으로 보스가 패턴을 한 번도 못 쓴다 ([#105](../../issues/105)).

### 플레이어

`maxHealth 30`. 적 데미지가 5~10 이라 **6대 안팎에 죽는다.**

## 알려진 문제

### 절단된 것 — 의도한 것이다

```
시작 화면          없다. 실행하면 바로 1층 (#120)
일시정지 · 설정     없다. 종료는 Alt+F4
보스 페이즈 2       1페이즈만 (#106 후속)
유물               통째로 1차 범위 밖
무기 스킬          1차 범위 밖 (#51 · #52)
사운드 · 이펙트     절단
영어               String Table 이 한국어만 채워져 있다
```

### 임시로 둔 것

| | 왜 |
|---|---|
| **보상방이 회복만 준다** | 3택 1 은 [#102](../../issues/102) 본편. 지금은 방에 들어가면 자동 회복 |
| **재시작이 `R` 키** | [#103](../../issues/103) 이 버튼으로 바꾼다 |
| **결과 화면 문자열이 하드코딩** | `StageRunner` 가 한국어를 직접 조립한다. String Table 을 안 탄다 ([#103](../../issues/103)) |

### 남아 있는 문제

- **[#108](../../issues/108) 원거리 적이 붙으면 아무것도 못 한다.** `Pattern_Shoot.minRange`
  를 0 으로 내려 증상은 없앴지만, 물러서는 행동이 없다는 얕음은 그대로다
- **맞은 티가 잘 안 난다.** 활은 `knockbackForce 0.5` 라 적이 안 밀린다. 손맛 재조정이
  절단돼서 후속이다
- **죽은 뒤 적들이 시체 주위에 모인다.** 허트박스가 꺼져 있어 아무 일도 안 일어난다.
  결과 화면이 덮으면 안 보인다
