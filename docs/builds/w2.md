# W2 빌드 노트 — v0.2

> 2026-08-14 · 태그 `w2` · Windows x64
> 관련: [W1 빌드 노트](w1.md) · [W2 빌드 계획](w2-plan.md) · [GDD](../GDD.md) · [개발 로드맵](../roadmap.md) · [학습 로그](../learning-log.md)

W2 "무기 교체 시스템" 종료 시점의 검증용 빌드. **배포용이 아니다.**
목적은 W1 과 같다 — 손맛을 에디터 밖에서 확인하는 것, 그리고 **에디터에서는 안 보이는
빌드 전용 문제를 찾는 것**.

계획서대로 두 번 눌렀다. [#45](../../issues/45) 직후 한 번, W2 종료 시점에 한 번.

---

## 조작

| 동작 | 키보드 | 게임패드 | 상태 |
|---|---|---|---|
| 이동 | `←` `→` | 왼쪽 스틱 / D-pad | 동작 |
| 점프 | `Space` | A (남) | 동작 |
| 공격 | `F` | X (서) | 동작 |
| 스왑 | `A` | RB | **동작** — W1 에서 미구현이었다 |
| 스킬 1 | `D` | Y (북) | **이연** — 후속 ([#51](../../issues/51)) |
| 스킬 2 | `S` | B (동) | **이연** — 후속 |
| 상호작용 | `E` | LB | 미구현 — W3 |
| 일시정지 | `Esc` | Start | 미구현 — W5 |

스왑이 W1 의 "미구현"에서 동작으로 바뀐 유일한 항목이다. 스킬 둘은 구현하지 않기로
결정했으므로 **미구현이 아니라 이연**이다 ([로드맵](../roadmap.md) 절단 순서 1번).

**종료는 창 닫기 또는 `Alt+F4`.** 일시정지 UI 가 W5 라 게임 안에 종료 경로가 없다.
W1 과 같이 **창 모드 + 크기 조절 가능**으로 냈다.

## 들어 있는 것

W1 전부에 아래가 더해졌다.

- 무기 = **ScriptableObject 데이터 + 런타임 래퍼**
- 슬롯 2개 + **스왑** — 전진 대시 · i-frame · 쿨타임
- **애니메이터 오버라이드 교체** — 스왑하면 외형과 클립이 함께 바뀐다
- **투사체** — 활 평타
- 무기 3종(검 · 창 · 활)의 리치 · 타이밍 · 데미지 · 넉백 · 히트스탑 차이
- 지상 공격 중 전진

레벨은 평지 하나. 아트는 구매 에셋 그대로. 사운드 없음. UI 없음.

**이 빌드에는 검과 활만 들어 있다.** 창이 빠진 경위는 아래 "빌드하면서 나온 것".

**흔들림이 전부 0 인 것은 의도다.** 흔들림은 피격에만 둔다 ([GDD 12.2](../GDD.md)).

**DPS 를 거의 같게 잡았다.** 차이가 강함에서 나오면 한쪽만 쓰게 된다 — 리듬과 거리에서
나와야 한다. 창이 조금 높은 것은 후딜이 길어 빗나갔을 때 대가가 크기 때문이고, 활이 낮은
것은 원거리라 안전한 만큼의 대가다.

**절대 수치는 W3 에서 다시 본다.** 지금은 무기 간 비율만 잡았고, 적 3종 HP 를 정할 때
세 무기를 같은 배율로 함께 움직인다.

### 스왑 · 투사체

`dashSpeed` 12 · `dashTime` 0.2 · `iframeTime` 0.3 · `swapCooldown` 3.3

투사체 `speed` 12 · `lifetime` 2 · `pierce` 3

### 적 (더미) — W1 과 같다

`startup` 0.4 · `active` 0.15 · `recovery` 0.6 · 데미지 5 · 넉백 4 ·
히트스탑 0.05 · 흔들림 0.03 · 체력 30 · `moveSpeed` 2 · `attackRange` 0.9 ·
`deathDelay` 0.35

한 사이클이 **1.15초**다. 무적 0.6초보다 길어서 같은 적에게 연속으로 갈리지 않는다.

### 피드백 — W1 과 같다

`VelocityImpulse.defaultDuration` 0.2 · `Shake.duration` 0.12 ·
`Invincibility.duration` 0.6 · `blinkInterval` 0.08

W1 의 `Knockback` 이 `VelocityImpulse` 로 이름이 바뀌었다 ([#50](../../issues/50)).
넉백과 지상 전진이 같은 통로를 쓰는데 이름이 넉백이면 정직하지 않다.

## 알려진 문제

**W1 에서 해결된 것은 없다.** W2 는 무기 시스템 주차라 W1 의 잔여 문제를 건드리지 않았다.

**플레이어가 죽지 않는다.** `Health` 를 여전히 안 붙였다 — 씬의 `Health` 는 적 둘뿐이고
플레이어 `HurtBox` 의 `health` 슬롯이 비어 있다. 사망·재시작이 W4 라 갈 곳이 없다.
맞으면 넉백과 무적만 걸린다.

**시체가 때린다.** 적이 죽고 `Destroy` 까지 0.35초 동안 히트박스가 활성이다.
[#55](../../issues/55) 로 이슈화하고 **W3 으로 옮겼다** — `EnemyDummy` 가 W3 에서 클래스째
다시 짜이므로 지금 고치면 그대로 버려진다.

**적 둘이 겹친다.** `Enemy` ↔ `Enemy` 충돌을 껐다 ([#16](../../issues/16)). 여러 마리가
같은 지점을 추격하면 서로 튕겨나가기 때문이다. 겹쳐 보이는 것은 물리가 아니라 추격 AI 에서
간격을 두는 문제라 W3 에서 본다.

**낙하 포즈가 이륙 포즈와 같다.** 에셋에 하강 전용 그림이 없어서 체공 프레임을 붙잡아
쓴다 ([GDD 10.1](../GDD.md)). W2 에서 세 무기의 `Jump` 클립 타이밍을 통일하며 프레임을
2장으로 줄였지만 하강 포즈가 생긴 것은 아니다. W6 폴리시 항목.

**공격 중 피격이 공격을 끊지 않는다.** `TakeHit` 이 상태머신을 건드리지 않는다. 다만
**스왑은 공격을 끊는다** ([GDD 12.4](../GDD.md)) — 취소 경로가 하나 생겼다.

**체력이 화면에 안 보인다.** UI 가 W5 다. 적 체력은 콘솔 로그로만 확인된다.

### W2 에서 새로 생긴 것

**스킬이 없다.** [#51](../../issues/51)·[#52](../../issues/52) 를 후속으로 이연했다.
그래서 [GDD 4장](../GDD.md)이 "기본 리듬"이라 부른 **대기 무기 쿨타임 순환이 1차에는
없다.** 스왑은 회피기 + 평타 성격 전환으로만 작동한다.

## 빌드하면서 나온 것

**활이 빌드에 안 들어갈 뻔했다.** 계획서 2번이 경고한 그대로였다.

```
startingWeapons  [0] Weapon_Sword
                 [1] Weapon_Spear

Weapon_Bow       씬·코드 어디서도 참조 안 됨
```

**SO 는 누가 참조해야 빌드에 포함된다.** 에디터에서는 인스펙터로 끌어다 놓으면 되니 증상이
없다. 그대로 빌드했으면 활이 통째로 빠져서, 계획서 5번(투사체 수명은 오래 돌려야 드러난다)
을 검증할 방법이 없었다.

**검 + 활로 맞바꿔 빌드했다.** 창은 [#62](../../issues/62) 에서 방금 에디터로 확인했고,
**투사체 수명은 빌드에서만 드러나는 축**이기 때문이다.

근본 대응(무기 목록 SO 하나에 3종 담기)은 **W4 로 미뤘다.** 보상 시스템이 무기 풀을 만들
때 정면으로 만나므로, 그때 실제 소비자와 함께 짓는 게 맞다.

> `WeaponHolder` 의 슬롯 수는 하드코딩이 아니다 — `slots.Length` 로 도는 구조라 3개를
> 넣으면 3슬롯 순환이 된다. 다만 GDD 사양이 2슬롯이라 빌드가 실제 게임과 달라지므로
> 쓰지 않았다.

**W1 의 `CS0246` 은 재발하지 않았다.** Pixem 스크립트의 `using` 가드가 그대로 살아
있었다. W2 에서 캐릭터를 다시 굽지 않아서다 — 다시 구우면 되돌아간다
([GDD 10.1](../GDD.md)).

## 빌드 설정

| 항목 | 값 | W1 대비 |
|---|---|---|
| Unity | 6000.3.15f1 / URP 17.3 (2D Renderer) | 그대로 |
| 플랫폼 | Windows x64 | 그대로 |
| Company Name | `WeaponHero` | 그대로 — `persistentDataPath` 가 걸린다 |
| Product Name | `PersonalProject` | 그대로 — 게임 이름은 W5 에서 정한다 |
| **Version** | **`0.2`** | `0.1` 에서 올림 |
| Fullscreen Mode | Windowed | 그대로 — 종료 UI 가 W5 |
| Resizable Window | 켬 | 그대로 |
| 씬 | `SampleScene` 하나 | 그대로 |

출력은 `Builds/` 이고 `.gitignore` 로 제외한다.

**`Debug Build Layout` 은 이번에도 껐다.** 무기 이름이 실제 문자열로 나왔으므로
Addressables 번들을 들여다볼 이유가 없었다 — 비어 나왔다면 그때 켜고 다시 빌드하면 된다.

빌드는 `Assets/Settings/UniversalRP.asset` 과 `UniversalRenderPipelineGlobalSettings.asset`
에 셰이더 스트리핑 결과를 기록한다. `git diff` 에 뜨는 게 정상이다.
