> 2026-08-10 · Windows x64 · 태그 `w1` · 상세: [빌드 노트](1주차%20빌드%20노트.md)

## 결과

**W1 구현이 빌드에서 문제없이 실행됨** (플레이 확인).

## 검증 범위

| | |
|---|---|
| 확인한 것 | 빌드 산출 · 실행 · W1 기능 전반의 플레이 동작 |
| 확인 방식 | 직접 플레이 |
| 확인 안 한 것 | 장시간 구동 · 게임패드 · 다른 해상도 · 다른 PC |

W1 에 들어간 기능 — 좌우 이동, 가변 높이 점프, 코요테 타임, 점프 버퍼,
3타 콤보와 선입력, 히트박스·허트박스, 히트스탑, 넉백, 화면 흔들림,
피격 무적과 깜빡임, 더미 적 2마리의 추격·예고·공격·경직·사망.

**에디터와 다르게 동작한 것은 없었다.** 이번 빌드에서 찾으려던 게 그거였다.

## 빌드에서만 드러난 문제 — 1건

**유료 에셋(Pixem) 스크립트 세 개가 `using UnityEditor;` 를 `#if UNITY_EDITOR` 밖에 둠.**

클래스 본문은 가드 안이라 **에디터에서는 증상이 전혀 없고, 플레이어 빌드에서만
`CS0246`** 이 난다. 이 스크립트들은 asmdef 가 없어 `Assembly-CSharp` 로 들어가므로
플레이어 빌드의 컴파일 대상이다.

`using` 세 줄을 가드로 감싸 해결. **소요 10분.**

**에셋을 다시 임포트하면 되돌아간다.** 절차를 [GDD 10.1](../GDD.md) 에 남겼다.
