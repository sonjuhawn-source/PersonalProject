빠르다.

## 패턴 구분 — 처음엔 안 갈리는 것처럼 보였다

돌진이 근접 물기와 **같은 거리에서 공격하는 것처럼** 보였다. 실제로는 정상이고, 이유가 둘이다.

**1. 플레이어가 움직이는 동안은 발동 거리를 눈으로 못 잰다.** 빌드에 거리 표시가 없으니
둘 다 "적이 가까이 와서 때린다"로 보인다.

**2. 두 패턴의 사거리가 실제로 겹친다.**

```
Bite    0    ~ 0.95     weight 3
Lunge   0.8  ~ 1.6      weight 1
             ↑↑↑↑
        0.8~0.95 에서 둘 다 후보 — 가중치 3:1 로 갈린다
```

겹치는 구간에서는 같은 거리에서 둘 중 아무거나 나온다. **의도된 동작이고, 오히려 그래야
붙어 있을 때도 행동이 단조롭지 않다.**

### 돌진 거리는 맞아떨어진다

```
전진량   forwardSpeed 7 × startup 0.2 / 2 = 0.7 유닛
도달     hitboxOffset 0.4 + hitboxSize.x/2 0.35 + 상대 허트박스 절반 0.25 = 1.0

발동 1.6 → 전진 후 0.9 → 도달 안쪽
발동 0.8 → 전진 후 0.1 → 도달 안쪽
```

`VelocityImpulse` 가 선형 감쇠라 이동량이 `speed × duration / 2` 다. **발동 구간 전체가
도달 범위 안에 들어온다.**

전진 시간이 `startup` 에 묶여 있다는 점은 기억해둘 것이다. `startup` 은 "판정이 나오기까지의
시간"이라 **돌진 거리를 늘리려면 판정 타이밍도 같이 밀린다.** 지금은 0.2 로 둘이 맞아떨어지지만,
[#74](../../issues/74) 에서 돌진형을 본격적으로 만들 때 둘을 분리할지 다시 볼 자리다.

## 타일셋 — 파일로 확인

빌드 실행이 아니라 **임포트 설정 검증**이라 디스크에서 확정된다.

```
Floor Tiles1 · Floor Tiles2 · House Tiles · Other Tiles1 · Other Tiles2
spritePixelsToUnits: 32   filterMode: 0(Point)   overridden: 0
```

**플랫폼 오버라이드가 0개**라 PPU·필터를 가릴 것이 없다. LFS 포인터 문제도 없었다 —
타일이 화면에 정상 표시됐다.

계획서가 함께 요구한 *"타일이 캐릭터 옆에서 어색하지 않은가"* 는 별개의 미적 판단이고,
방 프리팹([#75](../../issues/75))이 생긴 뒤에 봐야 한다.

## 검증 범위

| | |
|---|---|
| 확인한 것 | 빌드 산출 · 실행 · W2 회귀 · 적 계열 신규 |
| 확인 방식 | 직접 플레이 + 임포트 설정 파일 검증 |
| 확인 안 한 것 | 게임패드 · 다른 해상도 · 다른 PC · **플레이어 피격**(미배선) |

플레이어 피격은 [노트](3주차%20빌드%20노트.md)의 "알려진 한계"에 적은 그대로다. `HurtBox.health`
가 비어 있어 **적의 공격이 체력을 깎지 않는다.** 예고·경직·판정은 전부 정상이라 겉으로는
전투가 도는 것처럼 보이는데, 맞아도 손해가 없어서 **피할 이유가 없는 상태**다.

## 이번 빌드에서 배운 것

**"확인 못 했다"와 "안 된다"를 섞지 않는 것이 중요했다.** 돌진이 이상해 보였을 때 수치를
계산해 결함이라고 판단할 뻔했는데, 근거로 쓴 값이 조정 이전 것이었다. 실제 에셋은
`startup 0.2` · `maxRange 1.6` 으로 이미 맞춰져 있었다.

**빌드 검증에서는 화면에서 본 것이 계산보다 앞선다.** 계산은 어떤 값을 근거로 했는지에
따라 틀리고, 그 값이 낡았는지는 계산 자체로는 드러나지 않는다.
