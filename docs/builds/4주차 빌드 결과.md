## 결과

**빌드 한 번에 통과, 실행 확인.** W2·W3 와 같다. **콘솔에 아무것도 안 떴다.**

**런 한 판이 처음부터 끝까지 돌아간다.** 시작 → 전투 → 보상 → 보스 → 결과 → 재시작.
로드맵이 W5 주말 산출물로 잡은 **"루프 완성"이 여기서 달성됐다.**

## 빌드에서만 드러날 수 있었던 것 — 셋 다 통과

에디터에서는 안 보이고 빌드에서 처음 도는 경로였다.

| | 왜 위험했나 | 결과 |
|---|---|---|
| **Localization · Addressables** | 참조 사슬이 없으면 빌드에서 빠진다. W2 에서 활이 그럴 뻔했다 | 보스방·보상방이 완주에서 나왔다 |
| **재시작의 `static`** | 빌드에는 도메인 리로드가 없어 `static` 이 살아남는다 | `R` 재시작 정상 |
| **콜라이더 `Polygons`** | 모든 물리 판정의 기반이 `Outlines` 에서 바뀌었다 | 접지 · 적 지형 인식 정상 |

**둘째가 이번 빌드의 진짜 관문이었다.** 로드맵이 *"최종 빌드에서 처음 나올 종류의 버그고
그때는 시간이 없다"* 고 미리 적어둔 항목인데, [#100](../../issues/100) 에서 런 상태를
`static` 이 아니라 `RunState` 인스턴스로 모아둔 것이 값을 했다 — 재시작이 새 인스턴스를
만드는 것만으로 초기화된다.

## 플레이 결과 — 문제 둘

기능은 의도대로 도는데 **읽히지 않는 것**이 둘 있었다. 둘 다 "안 되는" 게 아니라
"모르겠는" 종류다.

### 1. 적 근접·원거리가 외형으로 안 갈린다

돌진형과 원거리형이 **같은 스프라이트**를 쓴다. 행동으로는 갈리지만
(`maxHeightDiff` 0.5 대 100, 사거리 0.95 대 4) **붙어야 알 수 있다.**

원거리형은 거리를 둬야 하고 돌진형은 붙어야 하는데, **판단할 시점에 정보가 없다.**
[#96](../../issues/96) 이 이 항목이고 후속으로 내려가 있다.

> 보스는 PixelFantasy 라 확실히 구분된다. 잡몹 둘만 안 갈린다.

### 2. 보상방이 있는지 모를 뻔했다

들어가면 **자동으로 10 회복되고 끝난다.** 화면에 아무 표시가 없고 `Debug.Log` 만 찍힌다.
방 생김새도 전투방과 같아서 **거기가 보상방인지 알 방법이 없다.**

[#102](../../issues/102) 가 3택 1 을 넣으면 선택 화면이 뜨므로 자연히 해결된다.
다만 **"보상방에 들어온 것이 화면으로 드러난다"** 를 완료 조건에 넣어야 한다 — 3택 1 만
만들고 진입 표시를 안 넣으면 같은 문제가 남는다.

## 난이도 — 회복이 부족하다

```
플레이어 HP 30        적 데미지 5~10        6대 안팎에 죽는다

한 런의 적       방마다 4~12마리 · 전투방 5개  →  30마리 이상
회복 총량        보상방 2개 × 10  =  20
```

**적 30마리 이상을 상대하는데 회복이 최대 체력의 3분의 2다.** [#122](../../issues/122) 로
활이 약해져 처리 시간도 늘었다.

`difficulty` 와 `spawnCount` 가 따로 논다는 것도 드러났다.

```
Room_1  difficulty 1  spawnCount  4
Room_2  difficulty 1  spawnCount  8      ← 같은 난이도인데 두 배
Room_4  difficulty 2  spawnCount 12
```

방 순서가 랜덤이라 **첫 방에 12마리가 나올 수 있다.**

### 값으로 안 덮는다

`healAmount` 를 올리는 것은 한 줄이지만 **원인이 회복량이 아니다.** 지금 보상방은 선택이
없어서 절차다. 3택 1 이 서면 *"무기를 바꿔 처리 속도를 올릴까, 회복할까"* 가 생기고
그것이 난이도의 답이다.

**지금 덮으면 [#102](../../issues/102) 를 만들 때 판단 재료가 사라진다.** 회복량도 스폰 수도
`#102` 이후에 기준이 달라지므로 마지막 주 밸런스에서 한 번에 잡는다.

## 검증 범위

**빌드에서 확인한 것**

- 실행 · 8칸 완주 (전투 5 + 보상 2 + 보스 1)
- 보스 처치가 런 클리어로 이어진다
- 결과 화면 → `R` 재시작 → 새 시드로 다시 시작
- 낙하 복귀 · 출구 포탈 · 적 순찰

**확인 안 한 것**

- 게임패드 — 바인딩은 있지만 이번에 안 눌러봤다
- 영어 로케일 — String Table 이 한국어만 채워져 있고, 결과 화면은 문자열이 하드코딩이라
  로케일을 바꿔도 한국어가 나온다 ([#103](../../issues/103))
- 창 크기 변경 — `resizableWindow: 1` 인데 UI 가 따라오는지 안 봤다

## 이번 빌드에서 배운 것

**빌드 전에 정적으로 확인할 수 있는 것을 다 확인하니 왕복이 0 이었다.**

W1 은 `using UnityEditor` 로 깨졌고 W2 는 참조 사슬로 활이 빠질 뻔했다. 이번에는 누르기 전에
가드 · 빌드 씬 목록 · 컴파일 에러 · 테스트 값 잔류 · UI 배선을 파일로 훑었다.
**빌드는 확인하는 자리가 아니라 확인한 것을 증명하는 자리다.**

그리고 **기능이 도는 것과 읽히는 것은 다르다.** 이번에 나온 문제 둘이 전부 후자다 —
적 구분도 보상방 인지도 코드는 정상이고 화면이 말을 안 한다. 지금까지 빌드 결과가
"동작하는가"였는데 **루프가 완성되니 처음으로 "알 수 있는가"가 나왔다.**
