# 개발 로드맵

> 상태: **초안** · 최종 수정 2026-07-28
> 기간은 1인 개발 기준 추정치. 마일스톤별 **완료 판정 기준**을 반드시 통과한 뒤 다음으로 넘어간다.

관련: [GDD](GDD.md)

---

## 원칙

**손맛 검증이 최우선.** 기획 문서를 아무리 촘촘히 써도 조작감이 재미없으면 전부 갈아엎게 된다.
따라서 M1에서 전투 프로토타입만 먼저 뽑아 검증하고, 재미가 확인된 뒤에 시스템을 붙인다.

각 마일스톤은 **플레이 가능한 상태**로 끝난다. "코드는 다 짰는데 아직 실행은 안 됨"인 단계를 만들지 않는다.

---

## M1 — 전투 프로토타입 (약 3~4주)

목표: **무기 하나로 적 하나를 때리는 게 재미있는가**를 판정한다.

- 플레이어 이동 / 점프 / 코요테 타임 / 점프 버퍼
- 평타 콤보 1종 + 히트박스
- 히트스탑, 넉백, 화면 흔들림, 피격 무적
- 더미 적 1종 (예고 모션 → 공격 → 경직)
- 임시 박스 아트로 진행 (아트는 이 단계에서 신경 쓰지 않는다)

**완료 판정:** 아트가 박스여도 적을 계속 때리고 싶은가. 아니면 원인을 찾아 M1에 머문다.

---

## M2 — 무기 교체 시스템 (약 3~4주)

목표: 이 게임의 **정체성**이 성립하는지 검증.

- 무기 슬롯 2개 + 스왑 입력
- 스왑 = 전진 대시 + i-frame + 쿨타임
- 대기 무기 쿨타임 회복
- 무기 데이터 ScriptableObject화 → 무기 4종 (대검 / 단검 / 마법서 / 창)
- 무기별 고유 스킬 2종

**완료 판정:** 스왑을 아끼지 않고 계속 누르게 되는가. 무기 조합에 따라 플레이가 달라지는가.

> GDD 미결정 #2(스왑 공격 판정), #5(2단 점프)를 이 단계에서 실제로 붙여보고 결정한다.

---

## M3 — 로그라이크 루프 (약 3~4주)

목표: 런이 성립한다.

- 방 프리팹 10개 + 랜덤 배치
- 방 클리어 → 보상 3택 1
- 유물 시스템 (이벤트 훅 기반) + 유물 10종
- 스테이지 1 + 보스 1
- 사망 → 재시작 루프

**완료 판정:** 20분짜리 런 한 판이 처음부터 끝까지 돌아가고, 두 번째 런을 하고 싶어지는가.

---

## M4 — MVP 완성 (약 3~4주)

목표: **남에게 보여줄 수 있는 상태.**

- 적 4종으로 확충, 방 구성 다양화
- 메타 성장 최소 구현
- UI: 체력, 무기 슬롯/쿨타임, 보상 선택, 결과 화면
- 사운드 (타격음 우선), 이펙트 정리
- 아트 교체 (GDD 미결정 #1 결정 사항 반영)
- 밸런스 1차 조정

**완료 판정:** 게임을 모르는 사람에게 넘겼을 때 설명 없이 20분 플레이가 가능한가.

---

## M5 — 확장 (선택, MVP 검증 후)

MVP가 재미있다고 확인된 경우에만 진행. GDD 8장의 "목표" 열까지 물량 확충.

- 스테이지 2 + 보스 2
- 무기 8종 / 적 8종 / 유물 20종+
- 밸런스 정밀 조정
